# Пісочниця 02 — Біти не брешуть

Збірка: `g++ -std=c++17 -Wall -Wextra -Werror taskN.cpp -o taskN`

## Задача 1. Парне чи непарне

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | `7: 1 1`, `10: 0 0`, `-3: -1 1` | `7: 1 1`, `10: 0 0`, `-3: -1 1` | `x & 1` дивиться лише на молодший біт, а `%` зберігає знак діленого, тож `-3 % 2` дає `-1`. |
| Зміни одне | `(x & 1) == 1` | — | `x % 2 == 1` для −3 хибне (там −1), а `(x & 1) == 1` працює для будь-якого знаку. |

## Задача 2. Степінь двійки одним рядком

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | `1 так`, `2 так`, `6 ні`, `64 так`, `96 ні`, `0 так` | те саме | `x & (x - 1)` знімає наймолодшу одиницю, тож у степеня двійки (одна одиниця) лишається 0; у 0 одиниць немає, і `0 & -1` теж 0 — помилкове «так». |
| Зміни одне | `0 ні`, решта без змін | `0 ні`, решта без змін | Додане `x != 0` відсікає єдиний хибний випадок. |

## Задача 3. Геймпад в одному байті

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | `24: 0 0 0 1 1 0` | `24: 0 0 0 1 1 0` | UP виставили й скинули, лишились RIGHT (8) і A (16): 8 + 16 = 24. |
| Зміни одне | `26: 0 1 0 1 1 0` | `26: 0 1 0 1 1 0` | Два `^= LEFT` скасовують одне одного, а `^= DOWN` додає 2: 24 + 2 = 26. |

## Задача 4. Пастка пріоритету

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | не збереться | помилка `-Werror=parentheses` | Компілятор бачить підозрілий `&` поруч із `==` і з `-Werror` відмовляється збирати. |
| Зміни одне | без `-Werror`: `bit 2 is clear`; з дужками: `bit 2 is set` | `bit 2 is clear` / `bit 2 is set` | `==` зв'язує тісніше за `&`, тому `flags & 4 == 4` — це `6 & 1` = 0; з дужками це `4 == 4`, тобто істина. |

## Задача 5. Зсув замість множення

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | `40`, `144`, `-4` | `40`, `144`, `-4` | 5·8 = 40; 200·2 = 400 не влазить у байт, лишається 400 − 256 = 144; −16 >> 2 тягне знаковий біт, тож −4. |
| Зміни одне | `60` | `60` | `(uint8_t)-16` — це 240 без знака, і 240 / 4 = 60. |

## Задача 6. Колір у трьох байтах

| | Прогноз | Справжній вивід | Чому так |
|---|---|---|---|
| Передбачте | `255 136 0` | `255 136 0` | `0xFF8800` — три байти FF, 88, 00; кожен діставали зсувом до нуля й маскою `& 0xFF`. |
| Зміни одне | `fc40` | `fc40` | RGB565: R 5 біт (31), G 6 біт (34), B 5 біт (0) → `11111 100010 00000` = `0xFC40`. |
